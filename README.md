# Ad Cleaner

一个适用于 Chromium 系浏览器的 MV3 扩展，提供两层清理能力：

- 静态拦截常见第三方广告域名请求
- 在网页内标记疑似广告容器，并支持一键隐藏/恢复

## 使用方式

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启开发者模式。
3. 选择“加载已解压的扩展程序”。
4. 指向 `ad-cleaner-extension` 目录。

## 入口说明

- 弹窗里可以快速启用/关闭、重新扫描、清理或恢复。
- 弹窗里可以唤起误杀恢复面板。
- 弹窗里可以进入“点选屏蔽”模式，直接点击网页里的广告块生成当前站点的隐藏规则。
- `设置页` 会打开完整的站点规则管理界面。
- 白名单会放行当前站点并停止标记，黑名单会强制启用清理。
- 设置页里的“内置过滤”可以单独关闭，关掉后只保留订阅、手动选择器和站点规则。
- 自定义过滤和订阅源都会显示更明确的详情说明，方便判断它们会影响哪些内容。
- 弹窗里也可以直接切换内置过滤，不用每次都进设置页。
- TryBlock 测试页会自动进入低误杀模式，减少把整块测试内容误判成广告。
- 弹窗会显示启发式、自定义和订阅的命中统计，也会显示恢复过的数量，方便检查订阅是否生效。
- 浏览器扩展栏图标会显示当前标签页的网络拦截链接数量；已打包版本无法使用调试命中 API 时，会回退显示页面隐藏的广告元素数量，超过 999 条显示为 `999+`。
- 当前站点的自定义过滤现在以卡片形式展示来源、类型和影响范围。
- 设置页支持导入、导出和清空所有规则。
- TryBlock 这类演示广告本来就应该能被大多数广告拦截器识别；如果没拦住，不一定是扩展坏了，可能只是当前规则还不够完整。

## 主要行为

- 自动扫描页面里的广告容器候选
- 用红色描边和“广告”角标标记
- 识别到的广告会实时隐藏
- “恢复清理”会把隐藏节点重新显示
- 支持远程或文本过滤规则订阅
- 支持站点专用元素隐藏选择器
- 支持在页面里点选任意广告块，自动保存为站点专用隐藏规则
- 支持关闭内置静态规则，只使用订阅和手动规则
- 识别逻辑对新闻信息流、视频页和卡片流做了更强的启发式处理
- TryBlock 测试页会自动降级到低误杀模式，减少整页误杀
- 站点白名单会通过动态规则放行该站点的请求

## 说明

- 这是一个启发式方案，不可能 100% 命中所有广告。
- 对于“Sponsored / 广告 / 推广”一类的内容，命中率会更高。
- 如果某些站点结构特殊，可能需要再补一批规则或选择器。
