Ad Cleaner Tool-Ad-Cleaner — Privacy Policy

最后更新 / Last updated: 2026-08-07

1. 概述 / Overview

广告清理工具-Ad-Cleaner（以下简称“本扩展”）是一款浏览器扩展，用于拦截广告网络请求并隐藏页面上的广告元素。本扩展的设计目标是在用户本地设备上完全运行。

Ad Cleaner Tool-Ad-Cleaner ("the extension") is a browser extension that blocks ad network requests and hides on-page ad elements. The extension is designed to operate entirely on the user's local device.

2. 我们收集的数据 / Data We Collect

本扩展不收集任何用户数据。本扩展不收集、不存储、不传输任何个人身份信息、浏览历史、搜索查询、键盘输入或页面内容。

The extension collects zero user data. It does not collect, store, or transmit any personally identifiable information, browsing history, search queries, keystrokes, or page contents.

3. 本地存储使用 / Storage Usage

所有用户偏好设置（自定义规则、白名单站点、订阅列表、恢复记录、拦截统计计数）均存储在浏览器的 chrome.storage.local API 中，仅存在于用户设备本地，不会离开用户设备。

All user preferences (custom rules, allowlist sites, subscriptions, restore records, blocked counts) are stored exclusively in the browser's chrome.storage.local API. These settings never leave the user's device.

4. 网络访问 / Network Access

本扩展仅在以下两种情况下发起网络请求：

  • 声明式网络请求拦截：由浏览器网络栈在用户访问的页面发出子请求时进行匹配拦截，本扩展不读取请求或响应的内容。
  • 订阅列表下载：仅当用户手动添加第三方过滤列表 URL 时，本扩展会按刷新周期下载该规则列表。下载的列表存储在本地，不会转发给任何第三方。

The extension issues network requests for only two purposes: (1) Declarative Net Request blocking handled inside the browser's network stack without reading contents; (2) If the user manually adds a filter-list subscription URL, the extension fetches that list periodically. Downloaded lists are stored locally and never forwarded.

5. 第三方服务 / Third-Party Services

本扩展不集成任何第三方分析、广告或遥测服务。

The extension does not integrate with any third-party analytics, advertising, or telemetry services.

6. 权限说明 / Permissions

  • declarativeNetRequest — 拦截广告网络请求，不读取内容
  • storage — 本地保存用户设置，不上传
  • tabs / activeTab — 显示当前页面拦截统计，不记录历史
  • <all_urls> — 在所有网站执行拦截，不主动访问网站

7. 儿童隐私 / Children's Privacy

本扩展不针对 13 岁以下儿童，也不故意收集任何人的信息。

The extension is not directed to children under 13 and does not knowingly collect information from anyone.

8. 开源透明 / Open Source

本扩展代码完全开源，托管于 github.com/vex74/Ad-Cleaner，任何人均可自行审计。

The extension is fully open source at github.com/vex74/Ad-Cleaner and can be audited by anyone.

如有隐私相关问题，请在 GitHub 仓库提交 Issue：github.com/vex74/Ad-Cleaner/issues

For privacy questions, please open an issue at: github.com/vex74/Ad-Cleaner/issues
